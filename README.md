# VIGILA — Prototipo de vigilancia en tiempo real

## Descripción

VIGILA es un prototipo de sistema de vigilancia que permite visualizar
una transmisión de video en tiempo real desde una interfaz web.

## Avance actual

- Interfaz web desarrollada con Laravel.
- Visualización de una cámara en vivo.
- Transmisión de video mediante MediaMTX.
- Reproducción de video HLS con HLS.js.
- Servidor web configurado con HTTPS.

## Tecnologías

- PHP y Laravel
- JavaScript
- HLS.js
- MediaMTX
- Nginx
- Ubuntu Server

## Estado del proyecto

Prototipo funcional en desarrollo. La visualización en vivo ha sido
probada. La grabación y el almacenamiento de video no se consideran
funcionalidades confirmadas de esta versión.

## Seguridad

No publiques credenciales, claves privadas, archivos `.env` reales
ni contraseñas de los servicios.

## Nota

Este proyecto se encuentra en desarrollo y puede recibir mejoras.
